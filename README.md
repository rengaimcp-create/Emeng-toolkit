# Emeng Injector — Android Training Toolkit

Ini adalah proyek Android Studio awal yang menghasilkan aplikasi toolkit latihan mandiri.

## Fitur MVP
- Dashboard navigasi.
- Crosshair Studio dengan preview dan pengaturan lokal tersimpan.
- Preset sensitivitas yang tersimpan sebagai catatan.
- Training Arena dengan target dummy yang bisa disentuh dan skor.
- Visualisasi ESP demo dengan target dummy, kotak, label, dan jarak simulasi.

## Batasan
Aplikasi ini tidak menyuntikkan kode ke Free Fire, tidak memodifikasi memori game, tidak membuat aimbot/ESP untuk pemain online, dan tidak melewati anti-cheat. Sensitivitas disimpan sebagai preset aplikasi dan tidak mengubah setting game secara otomatis.

## Build APK
1. Buka folder proyek ini di Android Studio versi terbaru.
2. Gunakan JDK 17 jika diminta.
3. Tunggu Gradle Sync selesai.
4. Pilih Build > Build APK(s).
5. APK debug biasanya ada di `app/build/outputs/apk/debug/app-debug.apk`.

Proyek ini belum dikompilasi di lingkungan pembuatan file ini; lakukan build dan uji pada perangkat melalui Android Studio.
